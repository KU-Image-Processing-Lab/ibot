# GitHubのリポジトリをクローンする

GitHubのリポジトリをクローンするには、`git clone`コマンドを使います。

まずは、リポジトリをクローンしたいディレクトリに移動します。例えば、`~/Documents`ディレクトリにクローンしたい場合、以下のようにします。

```bash
$ cd ~/Documents
```

例えば、https://github.com/hirokatsukataoka16/FractalDB-Pretrained-ResNet-PyTorchというリポジトリをクローンする場合、以下のようにします。

```bash
$ git clone https://github.com/hirokatsukataoka16/FractalDB-Pretrained-ResNet-PyTorch.git
```

これで、`FractalDB-Pretrained-ResNet-PyTorch`というディレクトリが作成され、その中にリポジトリのファイルがクローンされます。

クローンしたディレクトリに移動するには、以下のようにします。

```bash
$ cd FractalDB-Pretrained-ResNet-PyTorch
```
