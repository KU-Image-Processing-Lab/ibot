# シェルスクリプト

## ルール

シェルスクリプトファイルを追加した際は、このREADME.mdに追記して一緒にプルリクエストを送ってください。

## 使い方

./example.transfuse_resnet10.shがサンプルファイルなので、特にこだわりない人はこれをコピーして使ってください。

```bash
$ cp ./example.transfuse_resnet10.sh ./transfuse_resnet10.sh
```

## 各ファイルの説明

| ファイル名 | 説明 |
|:-----------:|:----:|
| example.transfuse_resnet10.sh | TransfuseとResNet10を使用してMTLを行なうシェルスクリプト |
