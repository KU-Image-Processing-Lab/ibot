# 医用画像処理

## 環境構築

```bash
$ cd docker/{docker-compose.ymlがあるディレクトリ}
$ docker-compose up -d
```

## ディレクトリ構成

ディレクトリ | 説明
--- | ---
utils | 便利な関数
lib | モデルの定義
weights | モデルの重みファイル
snapshots | 学習済みモデルのスナップショット
scripts | 実行スクリプト
dataset | データセット

## このリポジトリの意義

医用画像処理に関するコードを共通化するためのリポジトリです。

## ルール

1. mainに直接コミットしてはいけません。
2. プルリクエストを送る前にmainブランチを最新の状態にしよう。
3. コミットメッセージはちゃんと書こう。
4. データセットやモデルの重みファイルはgitに上げないようにしよう。
5. ディレクトリ構成を変更する場合は、他の人に事前に相談しよう。

### ブランチの切り方

mainブランチには直接コミットせず、各自のブランチを切ってからmainブランチにプルリクエストを送ってください。

`feature/機能名` でブランチを作成してください。

```bash
$ git checkout -b feature/機能名
```

### プルリクエストについて

プルリクエストを送る前に、mainブランチを最新の状態にしてください。

```bash
$ git checkout main
$ git pull origin main
```

mainブランチを最新の状態にした後、プルリクエストを送ってください。

### コミットメッセージについて

コミットメッセージは日本語でいいです。

```bash
$ git commit -m "機能名: コミットメッセージ"
```
